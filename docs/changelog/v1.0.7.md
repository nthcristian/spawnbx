# Changelog

## 1.0.7

### Added

- Wayland socket and environment passthrough during container creation.
- Xwayland `DISPLAY` and X11 socket passthrough, with optional `$XAUTHORITY` or `$HOME/.Xauthority` forwarding.
- PipeWire socket passthrough.
- AMD GPU passthrough through `/dev/dri`.

### Testing

- Added integration-state unit coverage and isolated CLI coverage for Wayland, Xwayland, PipeWire, AMD GPU, and Xauthority fallback arguments.
