# Changelog

## 1.0.8 - First Production Release

### Available Workflows

- Create, attach, update, stop, remove, and recreate project-local Docker environments.
- Configure the mapped container user and reconcile Nix packages from `.spawnbx.yml`.
- Persist project container names, shells, package lists, integration settings, and missing-integration policy.

### Desktop Integrations

- Support Wayland socket passthrough and optional Xwayland/Xauthority forwarding when the host X11 socket is available.
- Support PipeWire socket passthrough.
- Support AMD DRM and NVIDIA GPU device detection during container creation.
- Validate required host integration resources before Docker creation, with an optional configuration policy to omit unavailable integrations.

### Quality

- Cover command parsing, settings persistence, lifecycle behavior, desktop integration arguments, and missing-integration behavior with isolated tests.
- Provide opt-in runtime tests for Docker, mapped user setup, and Nix profile behavior.
